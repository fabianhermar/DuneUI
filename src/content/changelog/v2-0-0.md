When we first launched DuneUI v1.0.0, our goal was straightforward: give frontend engineers clean, copy-pasteable interface building blocks without locking them into heavy component abstractions. Over time, however, modern web development shifted. Tailwind CSS v4 arrived with a faster, CSS-first engine, dark-mode expectations matured, and developers began demanding more than generic boilerplate cards—they wanted production-grade UX patterns with genuine visual character.

Today, we are proud to introduce **DuneUI v2.0.0**: a ground-up rewrite of both our platform architecture and our entire component catalog. Spanning **60 distinct UI categories** and **600 responsive, copy-pasteable components**, v2.0.0 brings together **Astro**, **Tailwind CSS v4**, full **Light & Dark mode parity**, and interactive preview tooling in one cohesive system.

---

## A Modular Architecture Built on Astro & Tailwind CSS v4

Under the hood, DuneUI v2.0.0 replaces legacy v3 configuration and monolithic data files with a clean, file-based snippet architecture powered by **Astro**. Each component family now lives in its own modular directory (`src/data/snippets/`) paired with lightweight `category.json` metadata and standalone HTML specimens.

- **Zero External Runtime Bloat**: Every interactive disclosure, drawer, filter bar, and configurator relies on semantic HTML5 (`<details>`, `<summary>`, `<dialog>`) and scoped vanilla micro-scripts—meaning zero required React/Vue wrappers or third-party CDN dependencies.
- **Native Tailwind CSS v4 Ready**: All 600 components compile cleanly with `@import "tailwindcss";` and modern color/spacing utilities.
- **Interactive Preview Workbench**: Every category page lets you inspect live specimens across **375px mobile**, **tablet**, and **full-width desktop** viewports, toggle between **Light, Dark, Mesh, and Muted** canvases, and copy clean HTML in one click.

## Reimagining E-Commerce & Application UI From First Principles

Rather than treating every category with the same repetitive template, v2.0.0 gives each of the **10 variants inside every family** its own visual personality—spanning **Linear dark ops**, **Stripe fintech**, **Apple Liquid Glass**, **Neo-Brutalism**, **Editorial serif**, and **Industrial hardware**.

### The Complete E-Commerce Suite (`#55–#60`)
- **Shopping Carts (`/components/shopping-carts`)**: Slide-over drawers, live free-shipping progress bars, promo code discounts, quantity controls, and cross-sell upsell strips.
- **Checkout Forms (`/components/checkout-forms`)**: Express Apple Pay / Link rails, multi-step shipping & payment forms, B2B VAT/Tax ID inputs, and real-time order calculation.
- **Product Overviews (`/components/product-overviews`)**: Full Product Detail Page (PDP) layouts with multi-image galleries, live color & material swatches, size matrices with out-of-stock waitlist states, and hardware configurators.
- **Order Summaries (`/components/order-summaries`)**: One-click copyable order IDs, carrier live trackers, downloadable B2B receipts, multi-parcel warehouse hubs, and self-service RMA exchange portals.
- **Category Previews (`/components/category-previews`)**: Dribbble-inspired asymmetric bento lookbooks, interactive room switchers, dark hardware shelves, and live-synced editorial indexes.
- **Category Filters (`/components/category-filters`)**: Comprehensive multi-facet filtering systems combining department checkboxes, price distribution histograms, color swatches, size grids, ratings, origin hubs, removable active filter chips, and live sorting.

### Upgraded Application UI & Disclosure Families
We also completely overhauled **Accordions (`/components/accordion`)**, **Select & Comboboxes (`/components/select-menus`)**, **Description Lists (`/components/description-lists`)**, **Feeds & Activity (`/components/feeds`)**, **Action Panels (`/components/action-panels`)**, and **Page Headings (`/components/page-headings`)**—transforming static lists into interactive command palettes, live activity timelines, workspace danger zones, and API schema drawers.

## Migrating From v1.x

DuneUI v2.0.0 is a breaking release relative to v1.0.0:

- Legacy Tailwind v3 utility classes and external CDN references have been removed in favor of **Tailwind CSS v4** syntax.
- Component catalogs now resolve from modular `.html` and `category.json` files under `src/data/snippets/`.
- If you are upgrading an existing project, ensure your stylesheet uses `@import "tailwindcss";` and copy the updated v2.0.0 HTML snippets directly from any category page.
