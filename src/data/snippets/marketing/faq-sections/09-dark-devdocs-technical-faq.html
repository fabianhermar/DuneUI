$ Which Node.js & package manager versions are required? +

Runs cleanly on Node 20 LTS+ with pnpm 9+ or npm 10.

$ Are Bun, Deno, and Cloudflare Workers supported? +

Yes — distributed strictly as pure ESM templates with zero native C++ addons.

$ How do I purge unused utility classes? +

Tailwind CSS v4 automatically tree-shakes unused tokens at build time down to ~2.4 kB gzipped.
