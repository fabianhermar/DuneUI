CORE How does DuneUI eliminate runtime JavaScript overhead?

Every disclosure, layout, and surface is authored with semantic HTML5 primitives (<details>, <dialog>) and pure Tailwind v4 utilities—shipping zero client-side hydration wrapper libraries.

STACK Can I paste these snippets directly into Astro, Next.js, or Vue?

Yes. Because components use standard HTML attributes and scoped data selectors instead of proprietary React context providers, they drop cleanly into Astro .astro files, Next.js Server Components, Laravel Blade, or SvelteKit.

THEME How is Light and Dark mode parity enforced across components?

Every surface pairs high-contrast daytime slate/stone tokens with calibrated zinc/obsidian dark tokens (dark:bg-zinc-950, dark:border-zinc-800), ensuring WCAG AA contrast in both themes automatically.

A11Y Are keyboard navigation and screen readers supported natively?

Native <summary> elements provide built-in Enter and Space toggling and announce expanded states to assistive technologies without fragile ARIA scripts.
